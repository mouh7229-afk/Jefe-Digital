# JEFE Digital — نشر الموقع

## الملفات
- `index.html`: الموقع كامل (العربية والإنجليزية).

## النشر على GitHub Pages
1. افتح مستودع `Jefe-Digital` على GitHub.
2. ارفع `index.html` إلى جذر المستودع واستبدل الملف القديم.
3. اضغط **Commit changes**.
4. من Settings → Pages تأكد أن النشر من الفرع `main` والمجلد `/(root)`.
5. انتظر قليلاً ثم افتح الموقع.
