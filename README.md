# JEFE Digital

## Mise à jour du site
1. Ouvrir le dépôt GitHub `Jefe-Digital`.
2. Choisir `Add file` → `Upload files`.
3. Envoyer ce fichier `index.html` à la racine du dépôt et remplacer l’ancien fichier.
4. Cliquer sur `Commit changes`.
5. Attendre quelques minutes puis ouvrir le site GitHub Pages.

Le design reprend la palette d’origine : fond charbon, texte clair et accent vert lime discret. Le site reste bilingue arabe/anglais.
