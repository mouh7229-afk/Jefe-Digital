# JEFE Digital

Site vitrine statique bilingue français / arabe, conçu pour GitHub Pages.

## Fichiers
- `index.html` : site complet.
- `README.md` : ce guide.

## Mettre à jour sur GitHub
1. Ouvrez le dépôt `Jefe-Digital`.
2. Cliquez sur **Add file → Upload files**.
3. Envoyez `index.html` et `README.md` depuis le téléphone ou l'ordinateur.
4. Si GitHub signale un fichier existant, choisissez de remplacer le fichier, puis cliquez sur **Commit changes**.
5. Dans **Settings → Pages**, sélectionnez la branche `main` et le dossier `/(root)`.

## WhatsApp
Le numéro utilisé dans les liens est `212699332502` (format international du numéro marocain 0699332502).
Le bouton WhatsApp Business utilise un lien Android visant le package officiel `com.whatsapp.w4b`. Selon les réglages du téléphone, Android peut quand même ouvrir WhatsApp classique. Pour forcer Business, vérifiez dans Android : Paramètres → Applications → WhatsApp Business → Ouvrir par défaut / Liens pris en charge. Gardez aussi le bouton WhatsApp classique comme solution de secours.

## Notes
- Le site est statique : il ne contient pas de base de données, de paiement ni de gestion de stock.
- Les prix affichés sont indicatifs et doivent être confirmés avec le client.
- Le bouton « العربية » permet de passer à l'interface arabe et au sens d'écriture RTL.
