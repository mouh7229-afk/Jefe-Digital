# JEFE Digital

Site vitrine pour présenter des services digitaux aux commerces et petites entreprises au Maroc.

## Fichier du site

- `index.html` : page principale.

## Personnalisation

Dans `index.html`, remplace `212600000000` par ton numéro WhatsApp au format international, sans `+` ni espaces.

Exemple : un numéro marocain qui commence par `06` s’écrit avec `2126`, et un numéro qui commence par `07` avec `2127`.

Tu peux aussi modifier les services, les prix et les textes avant de publier le site.

## GitHub Pages

1. Ajoute `index.html` et `README.md` à la racine du repository GitHub.
2. Ouvre **Settings**, puis **Pages**.
3. Dans les paramètres de publication, sélectionne la branche `main` et le dossier `/ (root)`.
4. Enregistre. Le fichier d’accueil doit s’appeler `index.html`.
