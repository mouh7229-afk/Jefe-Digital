2. Le bouton WhatsApp utilise le numéro fourni : 212699332502.
3. Pour le remplacer sans programmer :
   - Ouvrez index.html avec un éditeur de texte (par exemple Bloc-notes).
   - Cherchez 212699332502.
   - Remplacez-le par votre numéro WhatsApp au format international, chiffres uniquement.

   - Enregistrez le fichier.
4. Vérifiez aussi les prix, le nom JEFE Digital et les services avant de publier.

PUBLICATION GRATUITE — OPTION GITHUB PAGES
1. Créez un compte GitHub sur github.com.
2. Créez un nouveau dépôt public nommé exactement : jefe-digital
3. Cliquez sur Add file > Upload files, puis déposez index.html.
4. Cliquez sur Commit changes.
5. Dans le dépôt : Settings > Pages.
6. Sous Build and deployment, choisissez Deploy from a branch.
7. Choisissez la branche main et le dossier /(root), puis Save.
8. Attendez quelques minutes. L'adresse sera généralement :
   https://VOTRE-NOM-UTILISATEUR.github.io/jefe-digital/
